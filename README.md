# Light & Dark Theme Toggle

A simple frontend practice project that demonstrates a **Light and Dark mode toggle** using HTML, CSS, and JavaScript. The interface theme changes instantly when the toggle button is clicked.

## Features
- Toggle between Light and Dark themes
- Smooth UI theme switching
- Simple and clean layout
- Beginner-friendly JavaScript project

## Technologies Used
- HTML
- CSS
- JavaScript

## What I Learned
- DOM manipulation
- Event handling in JavaScript
- Dynamic theme switching
- Basic UI component design

## How to Run
1. Clone the repository
2. Open `index.html` in your browser

## Project Purpose
This project was built as part of my **frontend development practice** while learning JavaScript and UI interactions.
