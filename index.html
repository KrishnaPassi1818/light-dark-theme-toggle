UI Experiment: Light & Dark Theme Toggle

This page is a small practice project to experiment with a Light and Dark theme toggle using JavaScript. The goal is to understand how themes work in modern web interfaces by dynamically changing styles, colors, and layouts based on user interaction.
Theme toggles are commonly used in modern applications to improve accessibility, readability, and user comfort, especially in low-light environments.
Use the toggle button to switch between themes and see how the interface adapts instantly.
